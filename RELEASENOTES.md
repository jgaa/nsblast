# nsblast Alpha Release

This is an alpha release and is not considered stable.

## Container Images

Container image publishing has moved from Docker Hub to GitHub Container Registry (GHCR).

Official image repository:
`ghcr.io/jgaa/nsblast`

## Summary Of Recent Changes

- Added GitHub Actions workflow for container build and publish to GHCR.
- Updated security workflows and dependency audit handling.
- Improved CI/workflow stability around publish and security jobs.
- Updated project documentation to reflect current build and image distribution paths.
